COMMANDES RAPIDES

Installation:
  npm install

Exécuter les tests:
  npm test                           # Tous les tests
  npm test -- test/aiService.test.js # Unitaires seulement
  npm test -- test/aiIntegration.test.js # Intégration seulement

Mode watch (re-exécute à chaque changement):
  npm run test:watch

Couverture de code:
  npm run test:coverage

Scripts helper:
  ./run-tests.sh all       # Tous les tests
  ./run-tests.sh ai        # Tests IA
  ./run-tests.sh coverage  # Avec couverture
  ./run-tests.sh watch     # Mode watch
  ./verify-tests.sh        # Vérifier setup
